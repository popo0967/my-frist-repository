## 1．LDAモデルの数式

潜在ディリクレ配分法（Latent Dirichlet Allocation: LDA）は、テキストデータなどの離散データ集合に対してトピック（隠れたテーマ）を割り当てるための確率的階層ベイズモデル（生成モデル）です。以下に、その数理的定義と同時確率分布の構成を示します。

### 1.1 前提定義と表記

分析対象とするデータ全体の構成要素を以下のように定義します。
* $M$: 全文書数（データセットに含まれる文書の総数）
* $N_d$: 文書 $d$ に含まれる単語の総数
* $K$: あらかじめ設定するトピックの総数
* $V$: 語彙の総数（重複を除いた全単語の種類数）

### 1.2 確率変数とハイパーパラメータ

モデルを構成する変数およびパラメータは以下の通りです。
* $\alpha$: 各文書のトピック分布に対するディリクレ事前分布のハイパーパラメータ（長さ $K$ のベクトル、または対称ディリクレ分布を仮定する場合はスカラー）
* $\beta$: 各トピックの単語分布に対するディリクレ事前分布のハイパーパラメータ（長さ $V$ のベクトル、またはスカラー）
* $\theta_d$: 文書 $d$ におけるトピックの多項分布パラメータ（長さ $K$ の確率ベクトル）
* $\phi_k$: トピック $k$ における単語の多項分布パラメータ（長さ $V$ の確率ベクトル）
* $z_{d,i}$: 文書 $d$ の $i$ 番目の位置にある単語に割り当てられる潜在トピック（$1$ から $K$ までの値をとる離散変数）
* $w_{d,i}$: 文書 $d$ の $i$ 番目の位置に観測される実際の単語（$1$ から $V$ までの値をとる観測変数）

### 1.3 確率的な生成プロセスと各条件付き確率

LDAは、データが以下の確率分布の連鎖によって生成されたと仮定します。

1. **トピックごとの単語分布の生成**
   各トピック $k \, (1 \le k \le K)$ は、語彙全体の確率分布 $\phi_k$ を持ち、これはディリクレ分布からサンプリングされます。
   $$\phi_k \sim \text{Dirichlet}(\beta)$$
   その確率密度関数は以下のように表されます。
   $$p(\phi_k \mid \beta) = \frac{\Gamma(\sum_{v=1}^V \beta_v)}{\prod_{v=1}^V \Gamma(\beta_v)} \prod_{v=1}^V \phi_{k,v}^{\beta_v - 1}$$
   ここで $\Gamma(x)$ はガンマ関数です。

2. **文書ごとのトピック比率の生成**
   各文書 $d \, (1 \le d \le M)$ は、自身が持つトピックの比率 $\theta_d$ を持ち、これもディリクレ分布からサンプリングされます。
   $$\theta_d \sim \text{Dirichlet}(\alpha)$$
   確率密度関数は以下の通りです。
   $$p(\theta_d \mid \alpha) = \frac{\Gamma(\sum_{k=1}^K \alpha_k)}{\prod_{k=1}^K \Gamma(\alpha_k)} \prod_{k=1}^K \theta_{d,k}^{\alpha_k - 1}$$

3. **潜在トピックのサンプリング**
   文書 $d$ 内の $i$ 番目の単語位置において、割り当てられるトピック $z_{d,i}$ が文書のトピック比率 $\theta_d$ に基づく多項分布（カテゴリカル分布）から選ばれます。
   $$z_{d,i} \sim \text{Categorical}(\theta_d)$$
   $$p(z_{d,i} = k \mid \theta_d) = \theta_{d,k}$$

4. **観測単語のサンプリング**
   選ばれたトピック $z_{d,i}$ に対応する単語分布 $\phi_{z_{d,i}}$ に基づき、実際の単語 $w_{d,i}$ がサンプリングされます。
   $$w_{d,i} \sim \text{Categorical}(\phi_{z_{d,i}})$$
   $$p(w_{d,i} = v \mid z_{d,i} = k, \phi_k) = \phi_{k,v}$$

### 1.4 全変数の同時確率分布

以上の生成プロセスに基づき、すべての観測変数 $\mathbf{W}$、潜在トピック $\mathbf{Z}$、およびパラメータ群 $\Theta, \Phi$ の同時確率分布は、各条件付き確率の積として以下のように定式化されます。

$$p(\mathbf{W}, \mathbf{Z}, \Theta, \Phi \mid \alpha, \beta) = \left( \prod_{k=1}^K p(\phi_k \mid \beta) \right) \prod_{d=1}^M \left( p(\theta_d \mid \alpha) \prod_{i=1}^{N_d} p(z_{d,i} \mid \theta_d) p(w_{d,i} \mid \phi_{z_{d,i}}) \right)$$

### 1.5 統計的推論の目的

この統計モデルにおける最終目標は、実際に観測されたテキストデータ（単語集合 $\mathbf{W}$）を与えられたもとでの、潜在変数およびパラメータの事後分布を求めることです。

$$p(\mathbf{Z}, \Theta, \Phi \mid \mathbf{W}, \alpha, \beta) = \frac{p(\mathbf{W}, \mathbf{Z}, \Theta, \Phi \mid \alpha, \beta)}{p(\mathbf{W} \mid \alpha, \beta)}$$

しかし、分母にある周辺尤度（エビデンス） $p(\mathbf{W} \mid \alpha, \beta)$ は、すべての潜在変数について積分・和を計算する必要があり、数理的に厳密な解（解析解）を求めることが困難（Intractable）です。そのため、Pythonのライブラリ（scikit-learnやGensimなど）では、**変分ベイズ法（Variational Bayes）**や**虚脱ギブスサンプリング（Collapsed Gibbs Sampling）**といった近似推論アルゴリズムを用いてパラメータの点推定または事後分布の近似を行います。
