## 2. スタッキング（モデルのカスケード結合）による高度化

本プロジェクトでは、機械学習における強力なアンサンブル手法である「スタッキング（Stacking）」を実装し、モデルの予測精度を限界まで引き上げています。

### 2.1 実践的なスタッキング（Stacking）の仕組み

現在のデータサイエンス実務やKaggle等で最も一般的に使われる強力なスタッキングは、**「1段目のモデルが作った予測値（OOF）を、元の説明変数（生データ）に新しい列として合流させ、それを2段目のモデルに入力する」**というアプローチです。

データリーク（未知のデータの覗き見）を防ぐため、1段目の予測値は必ず「K-Fold交差検証」を用いて作成します。

#### 【一般的な実践的スタッキングの構造図】

```text
       【 元の学習データ (特徴量X) 】
             │             │
             │             ▼ (K-Fold 交差検証で学習)
             │      [ ステージ1: 基本モデル群 ]
             │   ┌─────────┴─────────┐
             │ モデルA (XGB)       モデルB (LGBM)
             │   └─────────┬─────────┘
             │             ▼
             │       【 OOF予測値 】 (メタ特徴量)
             │             │
             └──────▶ [ 結 合 ] ◀──────┘ (元のデータに右付けで合流[説明変数、モデルの予測値1,モデルの予測値2,...])
                           │
                           ▼
          【 新しい学習データ (元の特徴量X ＋ OOF予測値) 】
                           │
                           ▼
                [ ステージ2: メタモデル ]
                 (例: 線形回帰, DNNなど)
                           │
                           ▼
                      【 最終予測値 】


### 2.2 今回のアーキテクチャ設計 (XGBoost + DNN カスケードモデル)

本プロジェクトで構築したモデルは、スタッキングの概念を応用し、モデルの予測値を元の特徴量に結合して次段のモデルに渡す**「直列型・残差補正アーキテクチャ」**です。

表形式データにおいて最強クラスの精度を誇る「XGBoost」を前段（ステージ1）に置き、その後段（ステージ2）として柔軟な非線形表現力を持つディープラーニング（DNN）を接続しています。

#### 【今回のカスケード結合の構造図】

```text
 【元の生データ】(8列)
 (緯度, 経度, 部屋数など)
          │             
          ├───▶ (5-Fold交差検証) ───▶ [ XGBoost ] ───▶ 【XGBoostの予測価格】(1列)
          │                                                  │
          └────────────────────────┬─────────────────────────┘
                                   ▼
                 【 結合データ (生データ + XGB予測価格) 】(9列)
                                   │
                                   ▼ (StandardScaler で正規化)
                                   │
                     [ Cascade DNN (64 ➔ 32 ➔ 1) ]
                     (Dropout: 0.2 / 活性化関数: ReLU)
                                   │
                                   ▼
                             【 最終予測価格 】
