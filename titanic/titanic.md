## 2. モデルの説明

* **モデル設定(1):決定木分類**

### 1. アルゴリズムの概要
決定木（Decision Tree）は、データの特徴量に基づいて「Yes/No」の条件分岐を繰り返し、データをグループに分割していくアルゴリズムです。
最終的に、同じグループ内に特定のクラス（例：タイタニックなら生存か死亡か）が固まるように分割を行うことが目標です。

### 2. 「分割の良さ」を決める指標
データをどこで切るかを判断するために、**「不純度（Impurity）」**という概念を使います。不純度とは「そのグループにどれくらい異なるクラスが混ざっているか」を表す指標です。

#### ① ジニ不純度 (Gini Impurity)
あるノード（集団）における「汚れ具合」を計算する最も一般的な指標です。
クラス $i$ の出現確率を $p_i$ とすると、ジニ不純度 $G$ は以下の式で定義されます。

$$G = 1 - \sum_{i=1}^{n} p_i^2$$

* **意味**: 全員が同じクラスなら $G=0$（純粋）、半分ずつ混ざっているときに最大になります。
* **特徴**: 計算が高速であるため、Scikit-learnのデフォルト設定として採用されています。

#### ② エントロピー (Entropy)
情報理論における「不確実性（乱雑さ）」を表す指標です。
エントロピー $H$ は以下の式で定義されます。

$$H = -\sum_{i=1}^{n} p_i \log_2(p_i)$$

* **意味**: データの予測しにくさを示します。ジニ不純度と同様に、完全に分類されていれば $0$ になります。
* **特徴**: ジニ不純度よりも計算に少し時間がかかりますが、よりバランスの取れた（情報の詰まった）木ができやすい傾向があります。
また、不均衡のバランスをとるために重みを
$$w_j = \frac{n_{\text{samples}}}{n_{\text{classes}} \times n_{\text{samples}_j}}$$
のように定義することで、分類の不均衡さをなくすこともできる



### 3. 情報利得 (Information Gain)
アルゴリズムは、分割前と分割後の不純度を比較し、その差が最大になる条件を探します。この差を**情報利得**と呼びます。

$$\text{情報利得} = (\text{分割前の不純度}) - (\text{分割後の不純度の加重平均})$$

決定木は、この情報利得が最大（＝最もデータがスッキリ分かれる）となる特徴量と閾値（しきいち）を、すべての候補の中から探索します。

### 4. 学習のプロセス
1. **全特徴量の試行**: すべての変数（例：性別、年齢、運賃）について、どこで分けるのがベストか試算する。
2. **最適な分岐の選択**: 情報利得が最大になる条件でデータを2つに分ける。
3. **再帰的分割**: 分けられた各グループに対して、さらに手順1〜2を繰り返す。
4. **停止条件**: 指定した深さ（`max_depth`）に達した、あるいはこれ以上分けても不純度が下がらない場合に停止する。


# モデル設定(2): XGBoost (eXtreme Gradient Boosting)

### 1. アルゴリズムの概要
XGBoostは、複数の決定木を組み合わせて強力な予測モデルを作る「アンサンブル学習」の一種です。特に**「勾配ブースティング（Gradient Boosting）」**という枠組みを使用しています。
最初に作った決定木が間違えた部分（誤差）を、次に作る決定木が修正し、さらにその次が修正し…というように、**直列に木を追加していくことで、徐々に正解に近づけていく**のが最大の特徴です。

### 2. 「分割の良さ」を決める指標（目的関数）
決定木では「不純度（ジニ係数など）」を使いましたが、XGBoostでは**「目的関数（Objective Function）」**を最小化するように学習を進めます。

目的関数 $\text{Obj}$ は、以下の2つの要素の足し算で定義されます。

$$\text{Obj} = \sum_{i=1}^{n} L(y_i, \hat{y}_i) + \sum_{k=1}^{K} \Omega(f_k)$$

#### ① 損失関数 (Loss Function: $L$)
実際の値 $y_i$ と、モデルの予測値 $\hat{y}_i$ がどれくらいズレているか（誤差）を表します。タイタニックのような分類問題では「Log Loss（交差エントロピー）」などが使われます。
XGBoostは計算を高速化するため、この損失関数をテイラー展開し、**一次微分（勾配: $g_i$）**と**二次微分（ヘッセ行列: $h_i$）**の2つの情報を使って誤差の方向と大きさを把握します。

#### ② 正則化項 (Regularization: $\Omega$)
モデルが複雑になりすぎる（過学習する）のを防ぐためのペナルティ（罰則）です。葉の数や、葉に割り当てられるスコア（重み）が大きくなりすぎないように抑え込みます。

#### 💡 不均衡データへの対応 (`scale_pos_weight`)
決定木における `class_weight='balanced'` と同様に、XGBoostでも不均衡データ対策が可能です。通常は `scale_pos_weight` というパラメータに以下の式に準ずる値を設定し、少数派（正例）の勾配を強調します。
$$\text{scale\_pos\_weight} = \frac{\text{多数派（負例）のサンプル数}}{\text{少数派（正例）のサンプル数}}$$

### 3. 分割の評価指標 (Gain)
XGBoostが木を枝分かれさせるとき、決定木の「情報利得」にあたる**「Gain（ゲイン）」**を計算し、これが最大になるポイントを探します。

あるノードを「左（L）」と「右（R）」に分割したときの Gain は、以下の式で計算されます。

$$\text{Gain} = \frac{1}{2} \left[ \frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda} \right] - \gamma$$

* $G$ : そのグループの勾配（一次微分）の合計
* $H$ : そのグループのヘッセ行列（二次微分）の合計
* $\lambda$ : 正則化パラメータ（スコアが極端になるのを防ぐ）
* $\gamma$ : 分割に対するペナルティ（Gainが $\gamma$ を超えなければ分割しない = 枝刈り）

**意味**: 「左のスコア」＋「右のスコア」から「分割前のスコア」を引き、それがペナルティ $\gamma$ を上回るなら、その分割は「価値がある」と判断します。

### 4. 学習のプロセス
1. **初期予測**: まず、全員に対して同じ値（例：0.5）を予測値としてはき出す。
2. **誤差の計算**: 実際のデータと予測値との誤差（勾配 $g_i$ と 二次微分 $h_i$）を全員分計算する。
3. **木を育てる**: その誤差を埋めるための「新しい決定木」を1本作成する（Gainが最大になるように分割していく）。
4. **予測のアップデート**: 元の予測値に、新しい木が出した結果を足し合わせる。このとき、極端な変化を防ぐために**学習率（Learning Rate: $\eta$）**を掛けて少しずつ足す。
   $$\hat{y}^{(t)}_i = \hat{y}^{(t-1)}_i + \eta f_t(x_i)$$
5. **反復**: 手順2〜4を、指定した木の数（`n_estimators`）に達するまで繰り返す。
